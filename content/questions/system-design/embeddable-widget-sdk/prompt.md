Your company sells a **customer-support chat and help-center widget**. Customers embed it on their websites with a
snippet. It is installed on **40,000 sites** with a combined **500 million page views per month**, ranging from small
WordPress blogs to large e-commerce sites with strict Content Security Policies.

The widget shows a launcher button, opens a chat panel, can show help articles, and offers a JavaScript API so the host
site can identify the logged-in user, open the widget programmatically, and listen to events (for example, "conversation
started").

Design the **embeddable widget SDK**: the snippet and loader, how the widget is isolated from the host page (and the
host from the widget), the host-facing API, versioning and rollout across 40,000 sites you do not control, security
(including identity verification), privacy and cookie restrictions, performance budgets, and how your team supports and
evolves it.
