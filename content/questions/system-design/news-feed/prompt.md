Design the front end of a **social news feed** similar to the Facebook home feed.

Users open the app and see a personalised, ranked list of posts from friends, groups and pages. They scroll
indefinitely, react to posts, open and write comments, and create new posts with text and images.

The interviewer gives you these constraints:

- Web client only (desktop and mobile web). Assume a backend ranking service already exists.
- Hundreds of millions of daily users, many on mid-range Android phones over 3G/4G.
- A single session can scroll through several hundred posts.
- Reaction counts and new comments should feel "live" but do not need to be perfectly real time.

Focus on the client: architecture, data model, API contract with the backend, and the performance and UX
techniques that make the feed fast and robust. You have about 45 minutes.
