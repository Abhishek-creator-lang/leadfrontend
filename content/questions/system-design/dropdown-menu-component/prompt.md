Design a reusable **dropdown menu component** for a design system: a button that opens a list of actions, like the
"⋯" overflow menu on a card, a user account menu, or a "File" menu with nested submenus.

Requirements:

- Items can be plain actions, links, checkbox items, radio groups, separators, group labels and submenus.
- Items can be disabled and can show icons and keyboard shortcut hints.
- The menu must stay visible and well positioned near screen edges, inside scrolling containers and inside modals.
- Full keyboard and screen reader support.
- Used by many teams, with different visual styles in some products.

Discuss the component API, positioning and layering, focus management, keyboard interaction, and how this differs
from a `<select>`-style listbox.
